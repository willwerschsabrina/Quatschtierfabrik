# QuatschSchrift – Schriftbibliothek

Freigegebene Arbeitsfassung vom 18.11.2026 für die Quatschtierfabrik und künftige Arbeitsblätter.

Die Schrift umfasst 59 Zeichen (A–Z, a–z, ÄÖÜäöüß) und verwendet die Liniatur 5:7:5.

**Wichtig:** Die Schrift ist eine SVG-Buchstabenbibliothek für HTML-Arbeitsblätter, keine installierbare TTF- oder OTF-Schrift. Die separate Bibliotheksdatei `QuatschSchrift_5-7-5.js` muss hier noch ergänzt werden. Bis dahin ist dies nur der angelegte Ablageordner.

Die aktuell veröffentlichte Quatschtierfabrik (`index.html`) wird dadurch nicht verändert. Die Druckdarstellung wird separat geprüft.
